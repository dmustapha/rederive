The problem

Agents recompute the world, every single time.

Ask an agent the same question twice and it pays twice — re-reading the same docs, re-scoring the same token, burning the same compute. There is no build cache for reasoning. Every answer is a cold start.

Redundant

Same input, same work

Nothing is content-addressed, so identical questions trigger identical spend. The agent has no memory of what it already proved.

Blind

One edit, full rebuild

Change a single source and the naive agent redoes all 24 checks — it can't tell which conclusions actually depend on what moved.

Costly
