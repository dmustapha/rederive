The problem

Agents recompute everything, every time.

There is no build cache for reasoning. Ask an agent to re-run due diligence and it re-reads the docs, re-scores the code, re-checks the token — burning tokens to re-derive facts that never changed. Reasoning has no make; every answer is a cold build.

How it works

Reasoning, treated like a build system.

01

A dossier is a DAG

6 sources feed 6 extractions, 15 metrics, and 3 conclusions — 24 derivations, each content-addressed by a hash of its inputs.

02

Only the cone re-derives

Same input hash = reused, free. New hash = recomputed. A mismatch auto-invalidates the downstream cone. Verify-on-serve.

03

Built for machines
