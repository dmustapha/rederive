The problem

Agents recompute everything, every time.

Ask an agent the same question twice and it pays twice. There's no build cache for reasoning — no memory of what it already derived, no way to reuse an answer that hasn't changed. Every dossier is a cold start.

No invalidation

How it works

Reasoning, treated like a build system.

6 sources → 6 extractions → 15 metrics → 3 conclusions = 24 derivations. Each is content-addressed by a hash of its inputs. Same hash = reused, free. New hash = recomputed.

DAG

A dossier is a graph

Sources feed extractions feed metrics feed conclusions — a dependency DAG, not a flat prompt.

CONE
