§ 01 The Problem

Agents recompute everything, every time.

Ask an agent the same due-diligence question twice and it re-reads every source, re-runs every metric, and re-pays for all of it — as if it had never seen the project before. There is no build cache for reasoning. Cognition is treated as disposable, and the invoice arrives in full on every single call.

Rederive treats a dossier the way a compiler treats a codebase: six sources feed twenty-four content-addressed derivations. Same inputs, same hash — reused, free. New hash — recomputed. A mismatch auto-invalidates the downstream cone. Nothing is recomputed by accident.

§ 02 How It Works

Reasoning, treated as a build system.

i.

A dossier is a DAG

6 sources → 6 extractions → 15 metrics → 3 conclusions. Twenty-four derivations, each addressed by a hash of its own inputs.

ii.

Only the cone re-derives

Change a source and its downstream cone is invalidated. Everything outside the cone is verified-on-serve and returned from memory.

iii.

Built for machines

The real customer is an AI agent, not a human. It calls a metered API and pays per answer with x402 on Base.

A build system for an agent's reasoning.
